# StudyDesk

A desktop assignment management application built with Python and CustomTkinter.

StudyDesk is a GUI-based productivity tool designed to help users organize and track their assignments. The application allows users to create tasks, manage due dates, monitor overdue assignments, and save their progress between sessions.

## Features

- Add and manage assignments
- Optional due dates
- Calendar-based date selection
- Overdue task detection
- Mark assignments as complete
- Delete assignments
- Save assignments between sessions using JSON

## Technologies Used

- Python
- CustomTkinter
- Tkcalendar
- JSON file storage

- Add reminders and notifications
- Improve task filtering and sorting
